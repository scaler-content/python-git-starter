Pull request workflow

How changes reach main in teams

git switch -c add-validation
# edit, test, then

On GitHub click Compare and pull request, describe the change, request a review, fix comments, then Merge.

Undo mistakes

Pick the smallest tool

git restore file.py           # discard edits
git restore --staged file.py  # unstage
git commit --amend -m "New message"  # fix last commit
git revert HEAD               # safe undo of a pushed commit

Avoid git reset --hard until you are confident: it deletes work.

Good commit messages

Reviewers read these

Add retry to shipping API client
Fix crash on empty order file
Validate order totals with Pydantic

Start with a verb, say what changed, keep it under about 60 characters, one idea per commit.
